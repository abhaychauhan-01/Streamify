#  Streamify

**Streamify** is a modern full-stack real-time communication platform built using the MERN stack. It provides secure authentication, real-time messaging, video calling, and social networking features in a clean and responsive interface.

Designed with scalability and performance in mind, Streamify follows modern full-stack development practices and is production-ready.

## ✨ Features
- 🔐 Secure JWT Authentication (Login & Signup)
- 👤 User Onboarding Flow
- 👥 Add & Manage Friends
- 💬 Real-Time One-to-One Chat
- 📹 High-Quality Video Calling
- 🎨 32 Beautiful UI Themes
- 🚨 Protected Routes & Authorization
- ⚡ Efficient Data Fetching with TanStack Query
- 🛠️ Custom React Hooks for Reusable Logic
- 🧪 REST API Testing for Reliable Backend Services
- 📱 Fully Responsive Design

## 🚀 Getting Started

### Clone the Repository
bash
git clone https://github.com/abhaychauhan-01/Streamify.git
### Navigate to the Project
bash
cd Streamify
### Install Dependencies
#### Backend
bash
cd backend
npm install
#### Frontend
```bash
cd frontend
npm install
```
## ⚙️ Environment Variables

Create a `.env` file inside the backend directory.

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
## ▶️ Run the Project

### Backend

```bash
npm run dev
```
### Frontend
bash
npm run dev
